Construí meu primeiro Sorteador de Números Online! 

Desenvolvi o Sorteador, uma aplicação web simples e intuitiva,
para realizar sorteios de números dentro de um intervalo definido pelo usuário.

 O que utilizei no projeto:

 HTML5: Para estruturar a página, usando as tags corretas e inputs semânticos (type="number").
 
 CSS3: Para criar um design moderno, centralizado e responsivo. Usei Flexbox para alinhar os elementos, 
 propriedades de transição e box-shadow para dar um efeito de profundidade flutuante no botão.
 
 JavaScript (ES6): Para dar vida à aplicação! Usei lógica de programação com Math.random() e Math.floor() 
 para gerar os números aleatórios a partir dos valores capturados nos inputs.

O maior aprendizado: Nesse projeto, consegui entender a fundo como funciona a manipulação
do DOM pelo JavaScript e como alinhar elementos perfeitamente com Flexbox no CSS, 
além de focar na usabilidade (UX) ajustando os placeholders para guiar o usuário.
